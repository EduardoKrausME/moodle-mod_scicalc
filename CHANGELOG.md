# Changelog

This changelog documents only the two most recent published GitHub releases. Each entry covers verified changes between its release tag and the immediately preceding published release. Later changes on `master` are excluded.

## 1.0.14 - 2026-10-15

### Changed

- Updated the existing plugin icon image at `pix/icon.png` and removed the separate `pix/icon.svg` asset.
- Updated the plugin release identifier from `1.0.13` to `1.0.14` and its build number from `2026101500` to `2026101501`.

No functional changes to the scientific calculator activity were identified between the published `1.0.13` and `1.0.14` tags.

[Compare 1.0.13...1.0.14](https://github.com/EduardoKrausME/moodle-mod_scicalc/compare/1.0.13...1.0.14)

## 1.0.13 - 2026-10-15

### Changed

- Updated the GitHub Actions CI PostgreSQL service from version 16 to 17.
- Updated the MariaDB CI service from version 10 to 11.4, including revised startup environment variables and health-check configuration.
- Updated the plugin release identifier from `1.0.12` to `1.0.13` and its build number from `2026101200` to `2026101500`.

No functional changes to the scientific calculator activity were identified between the published `1.0.12` and `1.0.13` tags.

[Compare 1.0.12...1.0.13](https://github.com/EduardoKrausME/moodle-mod_scicalc/compare/1.0.12...1.0.13)
